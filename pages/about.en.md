# About Awesome Remote Team Tools

Awesome Remote Team Tools is a curated, continuously updated directory of software that helps distributed teams communicate, plan and get work done — whether you're fully remote, hybrid or spread across time zones.

## What you'll find here

- **Communication** — chat, video, async updates and team engagement.
- **Planning and execution** — project, task and workflow management, scheduling and time tracking.
- **Knowledge and files** — documents, wikis, cloud storage and databases.
- **Automation** — tools that connect your stack and remove repetitive work.

## How the directory is maintained

The directory is built and maintained with the [Ever Works](https://ever.works) platform. AI agents research new tools, keep existing listings current and organize everything into categories and tags; every listing links back to the product's own site.

Using a tool your remote team can't live without? Use the **Submit** page to add it.
