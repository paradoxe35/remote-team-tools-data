## Overview

Tempo is a suite of products built specifically for teams using Jira. It provides time tracking, project planning, roadmapping, analytics, and financial management — all embedded within the Jira interface.

## Features

- **Automated Time Capture**: Simplifies time logging with automated capture functionality
- **Timesheet Approvals**: Streamlined approval workflows for managers
- **Reporting & Analytics**: Comprehensive reporting tools for tracking time and project progress
- **Project Planning & Roadmapping**: Plan and log time for individual tasks to ensure accurate project estimates and resource allocation
- **Billing & Cost Tracking**: Monitor budgets and profitability effectively
- **Jira Integration**: All features work seamlessly within the Jira interface without context switching
- **Resource Allocation**: Ensures accurate project estimates and optimal resource distribution

## Pricing

Pricing depends on which Tempo products are activated. The Timesheets product pricing is based on the number of Jira seats, starting from $4 per seat.

## Target Users

Primarily teams working in Jira, especially agile software development teams and project managers.
