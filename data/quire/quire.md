## Overview

Quire is a cloud-based project management software designed to help remote teams organize complex projects through an intuitive interface that balances simplicity with powerful features. It allows teams to set up members with different roles and permissions, create and manage tasks categorized into different projects, and collaborate seamlessly using a hierarchical structure.

## Features

- **Nested Task List**: Infinite nested task list with unlimited tasks and subtasks to break down big ideas into smaller, digestible tasks
- **Kanban Board**: Switch between nested task list and Kanban board at any time to get the best of both views
- **Sublist**: Create as many sub-lists as needed within a single to-do list to focus on what matters most
- **Timeline**: Gantt chart visualization for mapping out team schedules intuitively
- **Multiple Assignees**: Assign tasks to all responsible people
- **Schedule**: Set start date, start time, due date, and recurring date for task tracking
- **Project Template**: Duplicate a project or task to use as a template and save time
- **Reports**: Visual overview of project and team member performance
- **Smart Folders**: View and organize tasks from different projects in one place
- **External Team**: Outsource tasks to third parties without exposing everything in your projects
- **Share Links**: Send invitation links to clients so they can access projects without signing up
- **Export and Import Data**: Pain-free data migration or local backup export
- **Smart Keyboard Shortcuts**: Numerous shortcuts for mouse-free workflow
- **File Sharing**: Upload files or attach files from Google Drive directly to tasks
- **Integrations**: GitHub, Slack, Google Drive, iCal, Google Calendar, and more
- **Real-time Collaboration**: Data is updated in real time across mobile phones and web browsers

## Pros

- Interchangeable infinite nested task list and Kanban board
- Comprehensive collaboration features including multiple assignees and scheduling
- User-friendly and minimalist interface
- Cross-platform operations with iOS and Android mobile apps
- Smart search feature to locate information quickly
- Integrations with Slack, Google Drive, iCal, Google Calendar, etc.

## Cons

- Lack of various theme options
- No built-in chat feature (task-based comments updated in real time can be used instead)
