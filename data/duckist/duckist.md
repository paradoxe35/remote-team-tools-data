## Overview

Duckist is an encrypted messaging service designed for secure team communication. It allows team members to send messages that self-destruct after a predefined number of views or time interval, protecting sensitive information from unauthorized access.

## Features

- End-to-end encryption of messages
- Link-based delivery: messages are shared via a unique URL
- Configurable expiration: set message to expire after 1 day, 1 week, or 1 month
- View limit: specify allowed number of views before the message is destroyed
- No account required for recipients
- Protection against hacks, siphoning, and phishing
