## Overview
Dayboard is a productivity tool designed for remote workers who want to manage daily tasks effectively. It integrates with the browser's new tab page to display a prioritized to-do list.

## Features
- Create to-do lists
- Keep track of task progress
- Organize tasks in a single dashboard
- Collaborate with teams on tasks on a single platform
