## Overview

Hive is a project management platform designed to help teams plan work, collaborate efficiently, and gain visibility into productivity. It combines traditional project planning features with built-in analytics.

## Features

- Multiple project views: Kanban boards, Gantt charts, calendars, and tables
- Task assignment with deadlines, dependencies, and priorities
- Built-in dashboards for workload distribution, task completion, and team productivity insights
- Time tracking and resourcing features
- Comments, file sharing, and in-app messaging tied to tasks
- Performance analytics without relying on manual updates
- Desktop application available alongside web and mobile

## Platform Support

- Web-based
- iOS
- Android
- Desktop (Mac, Windows)

## Ideal For

Small to mid-sized teams that want flexible project management with built-in productivity insights and data-driven management.
