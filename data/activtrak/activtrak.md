## Overview

ActivTrak is a workforce analytics platform that focuses on using performance data to provide productivity insights rather than invasive surveillance. It does not capture employee screens, instead detecting activity through mouse movements and keyboard actions to classify users as active (engaged) or passive (disengaged).

## Features

- Activity tracking through mouse and keyboard monitoring
- Productivity analytics with dashboards displaying activity as charts and graphs
- Application and website monitoring
- Automated time tracking
- Team benchmarking and workload analysis
- Location insights correlating employee location with productivity levels
- Meeting-insights feature that checks employee calendars for time spent in meetings
- Site blocking and custom alerts
- Risk scores per user for potential policy infractions
- Custom reports and API access

## Integrations

- Over 20 integrations including Jira, Outlook, Microsoft Teams, Slack, and BI tools

## Pricing

Starting at $10 per user per month. Requires training due to complex data visualization.
