## Overview

Switchboard is an asynchronous collaboration tool designed to facilitate creative and interactive team collaboration in shared virtual workspaces. It offers interactive virtual rooms that mimic real-world team spaces, blending synchronous and asynchronous work to adapt to different team dynamics and workflows.

## Standout Features

- Interactive workspaces for team collaboration
- Persistent rooms that save work between sessions
- Built-in tools for creative collaboration
- Support for multiple file types and applications within rooms
- Ability to organize work by project, team, or topic
- Asynchronous-friendly design with persistent context

## Integrations

Google Drive, Dropbox, Figma, Miro, Slack, Trello, Jira, Zoom, Asana
